# DBinary
DBinary — это удобное графическое приложение для быстрого перевода любого текста в двоичный бинарный код и его обратной расшифровки. Программа работает в режиме «на лету» прямо во время ввода, поддерживает любые языки мира и оснащена кнопками для быстрой вставки, копирования, смены направлений и сброса настроек.
